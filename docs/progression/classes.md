# Classes & Class Tokens

Runaria replaces the default class menus with its own class archive. Pick a class, browse everything the server offers, and unlock advanced classes with a special currency: **Class Tokens**.

## How it works

- **`/class`** opens the class selection menu — the six base classes with a confirmation step. Selecting a class costs **1 class point**.
- **`/classes`** opens the full class archive, organised by category (Ranged, Rogue, Warrior, Summon, Magic, Support). Each class page shows its skills with live descriptions, and an **Unlock** button for classes you don't own yet.
- **12 classes are unlocked for everyone from the start:** Archer, Assassin, Warrior, Summoner, Mage, Shaman, and their six Awakened forms. Every other class costs **1 Class Token** to unlock.
- **Class Tokens** come as a physical golden token item — **right-click it to bank it** into your balance. Check your balance with `/classtokens balance`. Tokens drop from quest rewards, [Quest Boxes](../guilds/quests.md), and the Quest Shop.
- **`/subclass`** shows the subclasses of your current class. Promoting into a subclass **carries your level and progress over** and costs 1 class point. When you reach the level where a subclass opens up (level 30 for base classes), you'll get a one-time "Subclass Unlocked" announcement on screen.

!!! tip "Browse before you spend"
    `/classes` shows every class's skills — including ones you haven't unlocked — so you can read what a class actually does before spending a token on it.

## Commands

| Command | Aliases | What it does |
| --- | --- | --- |
| `/class` | — | Open the class selection menu (costs 1 class point) |
| `/classes` | — | Browse every class by category; unlock locked classes with Class Tokens |
| `/subclass` | `/sub` | Promote into a subclass once your class level is high enough |
| `/classtokens balance` | `/ctokens` | Check your Class Token balance |
