    Classes & Class Tokens¶

    Runaria has 44 playable classes across six categories. You start with a base class, promote into a subclass at level 30, and unlock the rest with Class Tokens.

    The commands¶

    Command What it does Cost
    /class Pick or switch your class 1 class point
    /subclass Promote into a subclass of your current class 1 class point
    /classes The Class Archive — browse every class by category, and unlock locked ones 1 Class Token
    /classtokens Check your token balance —

    Class Tokens¶

    Tokens drop as a glowing golden token item — "A shard of crystallized mastery." Right-click it to bank it into your balance. One token permanently unlocks one class. They come from quest rewards, Quest Boxes, and the Quest Shop.

    Twelve classes are free from day one: the six base classes and their six Awakened forms. Everything else costs a token.

    Unlocking and choosing are separate

    A token unlocks a class permanently. Actually becoming that class still costs a class point. Locks are hard-enforced — you cannot slip into a locked class from any menu.

    Promotion¶

    • Most subclasses unlock at class level 30.
    • A handful of second-tier Awakened promotions unlock at only level 15 of the intermediate class.
    • Your level carries over when you promote — you don't restart.
    • Hitting the threshold fires a full-screen "◆ SUBCLASS UNLOCKED ◆" announcement.

    Reading the class tables¶

    Every class caps at level 100, has 6 or 7 skills with the first slot reserved for a passive, and ultimates cap at skill level 20 while other skills reach 30.

    The four numbers are the server's own 0–10 ratings: Damage / Defense / Magic / Mobility. A few of the newest Awakened classes rate Support instead of Magic — those are marked ✦, and their third and fourth numbers read Mobility / Support instead.

    Skills and skill points¶

    You earn 1 skill point per class level, spent on levelling your class skills. Skills cap at level 30; your ultimate caps at 20.

    Ability Stones for your class's signature abilities are crafted at the Ability Gem Forge (/abilityforge). Each class has its own five-level ability line, and you only ever see recipes for the class you're currently playing.

    Levelling¶

    Levels 1 to 5 go by almost instantly. The curve jumps sharply at level 6 and climbs steadily from there — expect the last ten levels to take about as long as the first eighty.

    Class experience comes from killing mobs, from every profession level-up, and from party experience sharing — party members mirror each other's class experience, so grouping up genuinely levels everyone faster.
